# 🎧 SoundVisualizer

안드로이드 스마트폰 내부의 소리를 실시간으로 분석하고, AI 사운드 분류를 통해 화면에 시각화해주는 오버레이(Overlay) 애플리케이션입니다. 청각 장애인을 위한 환경음 알림 및 모바일 게임(FPS 등)의 사운드 플레이 보조를 목적으로 설계되었습니다.

---

## ✨ 주요 기능 (Core Features)

### 1. 🎙️ 실시간 시스템 오디오 캡처

안드로이드 **MediaProjection API**와 `AudioPlaybackCapture`를 사용해 기기 내부에서 재생되는 소리(게임, 미디어 등)를 직접 캡처합니다. 캡처는 전용 오디오 스레드에서 돌며, 사용자가 알림이나 시스템 UI에서 중단하면 즉시 정리됩니다.

### 2. ⚡ 할당 없는 오디오 레벨 엔진 (C++ NDK)

프레임 드랍의 원인이 되는 가비지 컬렉션을 없애기 위해, 오디오 레벨 측정을 **C++ NDK**로 구현했습니다.

- **Zero-Copy 전달**: `AudioRecord`가 direct `ByteBuffer`를 직접 채우고 JNI가 그 주소를 읽습니다. 코틀린 힙 복사가 없습니다.
- **Lock-Free 피크 측정**: 캡처 스레드가 버퍼별 채널 최대 진폭을 atomic으로 누적하고, 렌더 스레드가 프레임마다 읽으면서 초기화합니다. 호출당 할당이 0입니다.

### 3. 🧠 AI 사운드 분류

- **ONNX Runtime** 기반의 실시간 분류 파이프라인이 250ms 주기로 백그라운드에서 동작합니다.
- 16kHz 모노 리샘플링 → Log-Mel 스펙트로그램 → **YAMNet** 추론 → 3-클래스 매핑 → **Gunshot Booster** → 히스테리시스 후처리 순으로 진행됩니다.
- 결과에 따라 `Ambient(환경음)` / `Speech(대화음)` / `Danger(위협음)`로 분류하고, **시각화 색상과 표시 여부가 분류 결과에 따라 바뀝니다.** 색상은 설정에서 지정할 수 있습니다.
- 분류기는 시각화와 독립적으로 동작합니다. 모델 로딩 실패나 로딩 중에는 환경음으로 처리되어 시각화는 그대로 유지됩니다.

### 4. 📱 터치 통과형 투명 오버레이 UI (Jetpack Compose)

- **SYSTEM_ALERT_WINDOW** 권한을 사용해 모든 앱 위에 최상단으로 렌더링됩니다.
- `FLAG_NOT_TOUCHABLE` 속성을 적용하여, 시각화 그래픽 아래에 있는 게임이나 앱을 완벽하게 터치 및 조작할 수 있습니다.
- 렌더 루프는 프레임당 힙 할당이 없고, 화면 주사율과 무관하게 60fps로 제한됩니다. 소리가 없으면 그리기를 멈추고 저빈도 폴링으로 내려가 배터리를 아낍니다.

## 🎨 시각화 모드 (Visual Modes)

소리의 **크기와 방향**을 화면 둘레에 그려내는 4가지 표현 모드를 지원합니다. 스테레오 입력을 8방향(정면·측면·후면)으로 확장해 방향감을 표현하며, 모드별로 크기·진하기·속도·민감도·광원을 개별 설정할 수 있습니다.

- 🌊 **Wave 모드 (파도)**
  - 화면 테두리를 따라 소리의 세기에 비례해 요동치는 파도를 렌더링합니다. 소리가 나는 방향의 파도가 더 깊게 밀려듭니다.
- 🎯 **Pad 모드 (패드)**
  - 8방향 각 위치에 고정된 패드 형태로 소리의 세기를 표현합니다. 방향을 가장 또렷하게 읽을 수 있습니다.
- 🚨 **Outline 모드 (외곽선)**
  - 파도의 외곽선만 그려서 화면 가림을 최소화합니다. 게임 화면을 최대한 가리고 싶지 않을 때 적합합니다.
- ⭕ **Circle 모드 (원형)**
  - 화면 중앙을 기점으로 바깥으로 퍼져나가는 원형 파동을 그립니다. 중심부 반지름을 따로 조절할 수 있습니다.

## 🛠️ 기술 스택 (Tech Stack)

- **언어**: Kotlin, C++17
- **UI 프레임워크**: Jetpack Compose (Material 3)
- **오디오 캡처**: MediaProjection API, `AudioPlaybackCapture`, `AudioRecord`
- **DSP**: C++ NDK (JNI, lock-free atomic 피크 측정)
- **AI 추론**: ONNX Runtime (YAMNet + Gunshot Booster)
- **빌드 시스템**: Gradle (KTS), CMake (NDK)

## 🚀 시작하기 (Getting Started)

**요구 사항**: Android 10 (API 29) 이상. 내부 오디오 캡처(`AudioPlaybackCapture`)가 Android 10부터 제공됩니다.

1. **Android Studio**에서 본 프로젝트를 엽니다.
2. 프로젝트 동기화(Gradle Sync)를 완료하여 필수 라이브러리를 다운로드합니다.
3. 기기 또는 에뮬레이터에 빌드 및 실행(Run)합니다.
4. 앱에서 **실행**을 누르고 다음 권한을 허용합니다.
   - **다른 앱 위에 표시** (오버레이)
   - **오디오 녹음** (내부 소리 캡처에 필요)
   - **화면 녹화 / 캐스트** (MediaProjection)
5. 홈 화면이나 다른 앱(게임 등)으로 이동하면 화면 테두리에 실시간 시각화가 그려집니다.
6. 중단은 앱의 **실행 종료** 버튼 또는 알림의 **중지** 버튼으로 할 수 있습니다.
